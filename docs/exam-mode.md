# 阅读模考界面

新增 `/exam?id=<题目ID>`，进入后自动生成 `suiteSessionId`。题库卡片的时钟按钮和普通练习页的「单篇模考 · 20 分钟」按钮均可进入。原 `/practice-mode` 保留。

## 本地体验

```bash
npm ci
npm run dev:web -- --host 127.0.0.1
```

打开 http://127.0.0.1:5175/exam?id=p1-high-01 。无需启动 AI 后端即可进行本地答题与评分。

流程：示例身份确认 → 说明（实际题数、20 分钟）→ 开始计时 → 交卷确认 → 只读复盘。候选人编号仅是页面示例，不保存个人身份。

- 两栏独立滚动、可拖动分隔线；底部题号、前后题、Review 标记。
- 标题/匹配选项支持拖放及「点击选项，再点击空格」，空格也可通过 Enter/Space 操作。
- 单选/判断题在能够可靠识别题干的结构中折叠显示；导航会展开并聚焦答案。少数旧数据结构保持原样，避免丢失题目。
- 填空、摘要、表格和图示沿用仓库原有数据与评分；界面使用原题显示编号。
- 文章和题目中选词后右键可 Highlight、Notes、Clear、Clear all。
- Pause 暂停且遮挡试题；Hide 仅隐藏内容，时间继续走。
- 刷新当前 URL 可恢复倒计时和当前标签页中的草稿。提交结果保存到既有练习历史。
- 交卷前隐藏 AI 助教；交卷后可使用既有助教入口，实际请求仍依赖项目原有后端配置。

## 实现边界

单篇仍是 20 分钟模式，历史沿用原有 simulation 记录和统计。题库内容、答案和解析未批量修改。

草稿保存在 sessionStorage，时钟保存在 localStorage：承诺的是同一标签页刷新恢复，不是跨设备续考。存储不可写时可继续当前页作答，但不能保证离开页面后的恢复。

## 三篇完整模考

从题库页「完整阅读模考」进入 `/exam-setup`。分别选择 P1、P2、P3，也可随机组卷；每篇题数为 13、13、14，共 40 题。当前符合题型数据和编号条件的候选共 208 篇（66 / 66 / 76）。这些是题库自选组卷，并非官方原套卷。

准备完成后进入 `/exam-suite?passages=<三个逗号分隔的ID>&attemptId=<本次ID>`，统一使用 60 分钟时钟。底部 1–40 题可跨篇跳转，每篇分别保存答案、Review 标记、高亮和滚动位置。暂停、刷新恢复、到时自动交卷适用于整套考试。

交卷一次汇总 40 题总正确数、准确率、用时与分篇成绩，随后只读复盘。套题历史独立保存在当前浏览器 localStorage（`ielts_exam_suite_history_v1`，最多 50 条），不会重复写入三个单篇历史，也不做云同步。草稿仍限定当前标签页 sessionStorage；存储失败会保留草稿并提供重试保存按钮。
